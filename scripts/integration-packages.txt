# The tagged integration suite (scripts/integration-test.sh): one "<shard> <package>"
# line per package with integration-tagged test files. Every such package is listed
# exactly once (contracts/integration_entrypoint_test.go and make test check it). CI
# runs each shard as its own contract lane; the packages of a shard share one database
# and run one at a time. The shards are balanced by the time of their whole CI job,
# not by test time alone: shard 1 (./internal/app, about 2 minutes of tests) also runs
# the official Cargo replay and runs as a job of its own, shard 2 also runs the
# published backup test and shard 3 the Conan E2E. Each shard pays about 1.5 minutes
# to start its stack and compile. Runs 44738044844 and 44740891885 (amd64): 4.9 and
# 4.7, 8.4 and 6.0, 5.5 and 7.5 minutes per job, so issue #518 moved the four

# nexusmigration/pgstore 21 to 38 s, rubygemspublication/pgstore, objectstore and
# aptpublication) to shard 1. Shard 1 holds ./internal/app, so it also runs the
