# line per package with integration-tagged test files. Every such package is listed

# runs each shard as its own contract lane; the packages of a shard share one database
# and run one at a time, in this order. The shards are balanced by the time of their
# whole CI job, not by test time alone: shard 1 holds ./internal/app (about 2 minutes
# of tests), so it also runs the official Cargo replay, shard 2 also runs the
# published backup test and shard 3 the Conan E2E. Each shard pays about 1.5 minutes
# to start its stack and compile. Runs 44738044844 and 44740891885 (amd64), shards 1,
